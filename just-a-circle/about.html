About

I made a machine that takes a long way to draw one circle. Click the button and it picks a country. It finds the capital, checks the weather there, and uses the weather to draw.

The first API returns the capital's coordinates. The browser sends those coordinates to the weather API. It also uses the capital name to find a city photo on Wikipedia and Wikimedia Commons. The weather and photo requests both need data from the country response.

Temperature sets the color. Wind speed sets the size. Wind direction sets the position. If the weather request fails, the machine stops. If a photo is missing, it still makes the circle.

The result is small, but it takes data from two services to make it. That is the part I wanted to play with.

Data: World Bank and Open Meteo. Weather data is under CC BY 4.0.
