# Just a Circle

A small web project for class.

Click the button to pick a country. The capital coordinates go to Open Meteo. The weather changes the circle. The capital name is also used to find a city photo on Wikipedia and Wikimedia Commons.

Open index.html with Live Server in VS Code.

Files: index.html, about.html, style.css, and script.js.

Data: World Bank, Open Meteo, Wikipedia, and Wikimedia Commons. Photo credits are shown below each image.
